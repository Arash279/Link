## ppt/slides/slide3.xml
Current Method 
Core Algorithm: Two-stage optimization (global + local) (differential_evolution → least_squares), with multiple starting point selection.
Objective Function: Using the Re/Im residual of complex impedance (instead of log|Z|+phase), and introducing frequency weights (compute_freq_weights), scale normalization (MAD/STD), and robust loss (soft_l1/huber).
A
"more
 robust fit" version, which focuses on improving global search capabilities, outlier resistance, and diagnosing model defects from residual structure.

## ppt/slides/slide4.xml
Initial version
Core Algorithm: Single-step local optimization (
scipy.optimize.least_squares
).
Objective Function: Log10(|Z|) concatenated with the phase residual (phase difference using 
phase_diff_deg

The simplest "local least squares" baseline, fast, but prone to getting trapped in local optima and lacks global search or uncertainty estimation.

## ppt/slides/slide5.xml
NUTS
Core Algorithm: Based on 
CurVer
, Bayesian inference (NUTS in 
PyMC
) is added. First, global and local point estimates are obtained, then NUTS sampling is used to obtain the posterior distribution.
Objective Function: Still based on Re/
Im
 residuals, but expressed using a probabilistic model (
pm.Normal
 observation residuals), generating MAP and posterior mean.
A version with "uncertainty estimation" can output parameter distributions and confidence intervals, at the cost of a significant increase in computation.

## ppt/slides/slide9.xml
MLP-1: In-band Interpolation
Setup
Train on sparse points across entire band
Test on remaining points
Result
✔ Good fit in low/mid frequency
✘ High-frequency details are smoothed
Insight
MLP learns global trend, but suppresses high-curvature structures.

## ppt/slides/slide10.xml
MLP-2: Cross-band Extrapolation
Setup
Train: 10 Hz – 1e7 Hz
Test: 1e7 – 1e8 Hz
Observation
✔ Phase trend (upturn) extrapolated correctly
✘ High-frequency resonant structures not recovered
✘ Magnitude dip underestimated
Interpretation
MLP performs smooth extrapolation
but cannot generate new high-frequency dynamics.

Only adjust parameters theoretically dependent on power
Predict Dataset 2 (Power Level 2)
