## 1. Project Purpose

旧项目研究感应电机的宽频端口阻抗，主要频带为约100 Hz–100 MHz。旧工作主要建立在 **Mirafzal 2007/2009 模型复现**基础上，加入参数拟合、优化方法比较和实验性端口修正。

基础文献为 *Universal Induction Motor Model With Low-to-High Frequency-Response Characteristics*（2007）和 *Determination of Parameters in the Universal Induction Motor Model*（2009）。本地文献、代码与审计支持这一研究来源；实现与论文公式的逐项一致性尚未全面验证。

**当前远期目标是寻找更有物理可解释性、可验证性、足以发表的新研究方向，而不是继续单纯优化旧拟合。** 旧成果作为比较基线和问题线索；新贡献需要由文献差距、可证伪假设及独立验证共同支持。

## 2. Why This Remake Exists

项目中断后，脚本、报告与图表保留了不同阶段的结果：12参数消融与14参数主图并存，正文和代码存在不同拓扑，部分输出路径会复用或覆盖。报告是研究背景与过程记录，不能当作冻结的技术规范。

Remake 用于保留可复现资产、明确证据边界，并围绕值得研究的问题重新组织模型、数据和实验。历史文件保留，后续工作在本目录逐步建设。

## 4. What Is No Longer Assumed

- **不将“10–100 MHz 的阻抗反常转折是旧模型未覆盖的新现象”视为已成立结论。** 转折来源、既有模型的解释能力及文献覆盖情况均需重新核对；旧记录中的高频尾部不足不能直接升级为新现象或创新点。
- 不因14参数拟合较好就选定最终拓扑，也不预设端口修正元件就是接口或线材的真实等效参数。
- 不认为12参数消融严格验证了14参数主模型；旧算法比较的预算和起点配置也未完全对齐。
- 不认为 NUTS 已证明最优性或可靠的参数不确定性：旧脚本部分指标仍来自最小二乘解，缺少绑定主结果的采样诊断归档。
- 不把 GP 残差直接当作结构缺失或随机噪声的因果证据；不把同表验证或30HP试跑视为独立泛化验证。

## 5. Known Limitations

- **测量背景：** 目前已知资料为 SQLite 与接线表，缺少仪器、校准、夹具、去嵌入和原始导入记录。旋转／空载只是作者推测，工况仍未知。
- **参数解释：** 作者回忆将 `nLls` 从约 `1.7806e-2 H` 调到 `1.7806e-10 H` 是为改善拟合的有意调整，解析解释仍缺失。部分参数触及边界，物理可辨识性未建立。
- **验证范围：** 精确复现集中于一个主案例；其他接线曾参与参数提取，不能自动作为独立测试集。30HP套用默认先验属于时间限制下的不严谨试跑。
- **工程状态：** 归档脚本仍有原路径依赖，生成器可能覆盖人工增补；REMAKE 尚无完整、隔离的运行入口。
