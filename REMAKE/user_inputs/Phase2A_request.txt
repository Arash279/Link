基于你刚刚完成的 Phase 1 Audit，现在进入一个新的阶段：

# Phase 2A — Open Questions, Hypothesis Building, and Human Review

这一阶段的目标不是立即确定唯一正确答案，而是：

1. 系统列出目前仍未解决的主要问题；
2. 根据整个项目结构、代码、报告、数据、日志和历史文档进一步调查；
3. 对每个问题提出一个或多个可能解释；
4. 尝试判断哪个解释目前最合理；
5. 清楚地区分“事实”“推断”“猜测”；
6. 最后把结论交给我人工复核。

非常重要：

**不要把你推测出的最佳解释自动当作最终正解。**

即使某个解释非常合理，也必须保留：

- supporting evidence
- conflicting evidence
- alternative explanations
- confidence
- what would falsify this hypothesis

4. 是否可能图片和代码反而是后来版本？

输出证据链。

# 2. 每个问题使用统一模板

对每一个 open question，用如下格式记录：

## Qxx — Question

### Why it matters

解释为什么这个问题会影响 restart 项目。

### Confirmed evidence

只放可以直接从文件证明的事实。

必须给出具体路径、代码行、数据、日志或图。

### Candidate hypothesis A

解释。

Supporting evidence:
- ...

Conflicting evidence:
- ...

### Candidate hypothesis B

解释。

Supporting evidence:
- ...

Conflicting evidence:
- ...

必要时可以有 C、D。

### Current best interpretation

给出目前你认为最合理的解释。

但必须标记：

- HIGH confidence
- MEDIUM confidence
- LOW confidence

并写：

**This is a working hypothesis, not a confirmed conclusion.**

### How to verify

说明最有效的验证方法。

例如：

- 找到某个输出文件
- hash 对比
- 用保存参数重新生成 curve
- 从 PNG 提取元数据
- Git history
- 检查日志
- 运行某个脚本
- 比较预测值

# 5. 允许进行“受控推断”

这一阶段允许你根据项目结构进行分析和推测。

例如：

如果：

- 文件 A 在 3 月出现；
- 文件 B 在 5 月出现；
- report 使用 B 的 topology；
- workflow 后来又回到 A-like 12 parameter model；

可以提出：

“workflow 很可能是后来为了构造稳定 pipeline，而不是报告生成时的原始代码。”

但必须写成：

### Working hypothesis

而不是：

### Fact

并给出证据。

# 6. 不要只使用时间戳

时间戳只能作为辅助证据。

1. code behavior
2. imports
3. comments
4. report equations
5. output structure
6. git history
7. markdown research notes
8. timestamps

防止 copied files 导致时间顺序误判。

# 7. 尝试“解答”，但不要替我做最终决定

对于每个问题，你最终都应该有：

### Best current answer

例如：

> Best current answer:
> Report main result most likely uses the 14-parameter V3 topology implemented in `try/try.py`, while the later structured workflow uses the 12-parameter V2 model.
>
> Confidence: MEDIUM-HIGH.
>
> However, the exact parameter vector and figure-generation provenance remain unconfirmed.

这种形式是可以的。

不可以写：

> The report definitely uses try.py.

除非证据已经真正闭合。
