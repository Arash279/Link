## 1 尝试将Cad加在中性点-GND上，与Csf_0并联

结果：现在的拓扑里，Cad 是并在 Δ 网络的 b–c 边（Z4_0） 上的：Z4_0 = (Z3 || 0.5Z3 || (Csf0 || Cad))。Cad 变化会显著拉低这条边的阻抗，再经 Δ→Y 变换主要体现在 Z6、Z5 两个星形臂里（而串联臂 Z4 基本不变）。但在总阻抗里，这两个臂是以 Z6 + 0.5·Z1 和 Z5 + 0.5·Z2 的形式参与并联；因为 0.5·Z1 和 0.5·Z2 的量级远大于 Z6、Z5 的变化量，所以 Z6、Z5 的变化被直接“淹没”，总阻抗几乎不动。

具体数字（在 20 MHz 的抽样点）：

Z1 极大：|Z1| ≈ 4.138×10^3 Ω（约 4138 Ω），所以 0.5·Z1 ≈ 2069 Ω，这是左支路的主导项。

Z2 也不小：|Z2| ≈ 3.738×10^1 Ω（约 37.38 Ω），所以 0.5·Z2 ≈ 18.7 Ω，这是右支路的主导项。

而 Cad 改变带来的 Z6/Z5 变化，量级完全比不过上面这两个“半边”：

当 Cad = 1e-12 F：|Z4_0| ≈ 1.078 Ω，对应 |Z6| ≈ 1.071 Ω，|Z5| ≈ 9.68e-3 Ω。

当 Cad = 1.78e-7 F：|Z4_0| ≈ 4.30e-2 Ω，对应 |Z6| ≈ 4.27e-2 Ω，|Z5| ≈ 3.86e-4 Ω。

当 Cad = 1e2 F：|Z4_0| ≈ 7.96e-11 Ω，对应 |Z6| ≈ 7.91e-11 Ω，|Z5| ≈ 7.14e-13 Ω。

可以看到：Z6 从 ~1 Ω 被 Cad 拉到 ~1e-10 Ω（变化巨大），Z5 也从 ~1e-2 Ω 拉到 ~1e-12 Ω；但它们分别是被加在 ~2069 Ω（0.5Z1）和 ~18.7 Ω（0.5Z2）上——这种加法里，小项再怎么变也改不了大项的性质，所以并联支路、进而 Z_total 的感/容特性几乎无法被 Cad 调整。

## 2 尝试将Cad加在A、B、C三相共同接机壳点-GND之间（原Rf、Cf）

结果：在将 Cad 与 Csf0 串联 后，Cad 的变化会显著改变 Δ 网络 b–c 边的等效阻抗 Z4_0，并经 Δ→Y 变换主要反映到星形臂 Z6、Z5 上。例如，当

Cad = 1e-12 F 时，|Z_csf0_ad| ≈ 7.96 kΩ，|Z4_0| ≈ 7.96 kΩ，对应 |Z6| ≈ 3.66 kΩ、|Z5| ≈ 33 Ω；

Cad = 3.16e-9 F 时，|Z4_0| ≈ 3.59 Ω，|Z6| ≈ 3.57 Ω、|Z5| ≈ 0.032 Ω；

Cad = 1e2 F 时，|Z4_0| ≈ 1.08 Ω，|Z6| ≈ 1.07 Ω、|Z5| ≈ 0.0097 Ω。

可以看到，Z6 从 kΩ 级一路降到 ~1 Ω，Z5 从 ~33 Ω 降到 ~0.01 Ω，变化跨越多个数量级，说明 Cad 的作用链路是畅通的。

然而，总阻抗的组合形式为

$Ztotal​=((Z_6+0.5Z_1)∥(Z_5+0.5Z_2))+Z4$ ,

而在同一频点得到

|Z1| ≈ 4.14 kΩ → 0.5·Z1 ≈ 2.07 kΩ，

|Z2| ≈ 37.38 Ω → 0.5·Z2 ≈ 18.7 Ω。

因此，不论 Z6 是 1 Ω 还是 3.6 kΩ，左支路 Z6+0.5Z1 都是 kΩ 量级；不论 Z5 是 33 Ω 还是 0.01 Ω，右支路 Z5+0.5Z2 在大多数情况下都被 18.7 Ω 的 0.5Z2 主导。两支路并联时，结果始终由较小的右支路控制，而串联臂 Z4 又稳定在 ≈37 Ω 附近。最终，Z_total 被锁定在“几十欧”量级，Z6/Z5 的巨大变化被 0.5Z1、0.5Z2 与 Z4 这三个大项完全淹没，从而导致 Cad 无法有效调节电路的感/容特性。

## 总结

在 1e7–1e8 Hz 频段，从幅相曲线可以把各项的“角色分工”概括为：0.5Z1（蓝）幅值稳定在约 103.3 Ω（kΩ 量级），相位接近 0∘（近电阻/弱反应性），因此在并联结构中等价于“几乎开路”，使得左支路 (Z6+0.5Z1)永远被 0.5Z1钳在 kΩ 量级，而对 Ztotal贡献很小；0.5Z2（橙）在该频段幅值下降到十几欧量级，且相位长期靠近 −90∘（强容性），因此右支路 (Z5+0.5Z2) 的幅相几乎总由 0.5Z2主导并决定了并联部分的主要性质；Z5（红）在 1e7–1e8 Hz 幅值已远小于 1 Ω（趋近毫欧/微欧级），相位更偏向 −120∘∼−180∘（极强容性），但由于幅值太小，它在加法 Z5+0.5Z2中几乎被 0.5Z2直接淹没，难以改变右支路；Z6（紫）在高频也下降到 <1Ω 且相位接近 −90∘，但它出现在 Z6+0.5Z1里，被 kΩ 级的 0.5Z1​ 完全压制；最后 Z4（绿）在该频段是十几到几十欧量级、相位从负角度逐渐向 0∘ 靠近，并且它以串联项形式叠加在并联结果之后，因此对 Ztotal的幅值“锁定在十几～几十欧”起决定作用。综合起来，高频端可以近似理解为：并联部分主要由右支路（≈0.5Z2​）决定，而最终幅相再由串联的 Z4 进一步设定。

因此，在中性点（Neutral）或机壳公共点加电容/电阻（无论并联或引入串联支路）之所以无法改变整体阻抗的容/感性，本质原因有两层：第一，按你当前的 Δ→Y 等效路径，这类对地元件主要只会显著改变 Δ 网络某一边，从而体现在 Z5,Z6（以及部分情况下 Z4）的数值上，但在 1e7–1e8 Hz，Z5,Z6在总式中分别被 0.5Z2 与 0.5Z1​ 的“加法钳位”压住（小项再怎么变也改不了大项的幅相性质），导致并联部分的主导容性仍由 0.5Z2​ 决定；第二，即便对地元件通过 Δ→Y 变换同时推动了并联部分与串联臂（你观察到的 Z∥变大而 Z4​ 变小），它们也会在变换结构下呈现“反向耦合补偿”，使 Z∥+Z4​ 的复数和近似保持不变，最终 Ztotal​ 在该频段被结构性锁定，难以通过在 Neutral 或机壳处增减对地元件来实现“由容转感”的性质改变。

### 高频段（10–100 MHz）中调节 Z2、Z4 无法改善相位拟合的原因

通过分别对 Z2、Z4 的实部与虚部进行大范围扫描（仅观察相位响应），可以发现：  
无论如何调节这两个内部等效阻抗分支，在 10–100 MHz 频段内，仿真结果的相位始终保持容性或仅能接近 0°，而无法像实验结果那样明显转为感性。这表明，在该频段内，Z2 与 Z4 已不再是端口等效阻抗的主导项。

其根本原因在于：在高频极限下，等效电路被“对地电容通道”所主导。随着频率升高，相关电容支路的阻抗幅值按 1/ω迅速减小，相当于形成一条越来越接近短路的高频通道。相比之下，Z2、Z4 这类仅随频率缓慢变化、幅值有限的 lumped 阻抗项，对端口看到的总阻抗反应性影响变得微弱。  
因此，调节 Z2、Z4 只能在中频段（约 1e5∼1e7）内移动曲线位置，却无法改变高频段的相位符号。

---

### 为什么需要引入小电感（寄生/ESL）来解释实验高频相位

实验曲线在1e7-1e8Hz 范围内不仅出现相位由容性转为明显感性的趋势，而且伴随高频振荡起伏。这种特征更符合“寄生电感 + 分布效应”的典型表现，而非电机内部 lumped 元件的行为。

从数量级估算可知：  
若高频主导的等效对地电容在 nF 量级，仅需几十 nH 级别的串联电感，就足以在 10–100 MHz 区域与该电容产生相位翻转。这一数量级完全可能来自于测量回路、引线、机壳到地的几何回路或电容自身的 ESL，而非电机本体参数。

因此，单纯在模型内部调节 Z2、Z4 无法重现实验高频感性特征；要扭转 10–100 MHz 段的相位，必须在主导的对地电容通道或端口回路中引入小的串联寄生电感项。实验中高频相位的主要来源更可能是测量系统与回路几何结构，而非电机内部的 lumped 等效支路。

# 三阶段

## 1. 改一下拟合方法

### 1) 多起点 + 全局→局部精修（不改模型）

- **目的**：排除初值敏感/局部最优导致的“细节贴不住”。
    
- **做法**：
    
    1. 在参数 **bounds** 内生成 `N` 组初值（建议 _log-domain_ 均匀采样或 LHS；N=50~200）。
        
    2. 先跑一个**全局**（二选一：`differential_evolution` 或 CMA-ES；输出若干 top-K 候选）。
        
    3. 对每个候选解都用 `least_squares` 做**局部精修**（保留你原来的 bounds）。
        
    4. 记录每次的目标值、参数、收敛状态，挑最小的；也保留前 5 名用于对比“参数是否稳定”。
        
- **判别**：若 top 解之间目标差不多但参数飘 → 可能不可辨识/模型冗余；若全局+多起点明显改善细节 → 主要是优化问题。
    

### 2) 改残差到 Re/Im（复数域） + 频段权重

- **目的**：让优化器直接在复平面“贴形状”，减少相位 wrap/对数幅值的偏置，并强调关键频段细节。
    
- **做法**：
    
    - 残差向量改为拼接：`r = [ w(f)*((Re(Zm)-Re(Zd))/sRe), w(f)*((Im(Zm)-Im(Zd))/sIm) ]`
        
        - `Zm`=模型复阻抗，`Zd`=数据复阻抗
            
        - `sRe,sIm` 是归一化尺度（比如各自的中位数绝对偏差 MAD、或标准差，避免某一项主导）。
            
    - 频率权重 `w(f)`：
        
        - 最简单：对共振附近/转折段给更高权重（例如根据 |dφ/df| 或 |d log|Z|/df| 大的区间自动加权）。
            
        - 或按测量方差：`w=1/σ(f)`（如果你有重复测量/噪声估计）。
            
- **判别**：若 Re/Im + 权重后细节显著改善 → 多半是“目标函数/权重定义”问题，不一定要改模型。
    

### 3) 鲁棒损失（Huber / soft_l1 / Cauchy）

- **目的**：防止少量异常频点（接触不稳、仪器跳点、局部外界干扰）把整体解拉歪。
    
- **做法**：
    
    - 用 `least_squares(..., loss='soft_l1' 或 'huber', f_scale=...)`。
        
    - `f_scale` 用一个与残差尺度相当的值（可用初拟合残差的中位数绝对偏差 MAD 估计）。
        
    - 保持第 2 步的 Re/Im 残差结构与权重不变，只替换损失函数。
        
- **判别**：若鲁棒后细节变好且参数更稳定 → 说明数据存在离群/误差分布非高斯；模型未必缺项。
    

### 4) 电路模型 + GP 残差（用来“看模型缺口长什么样”）

- **目的**：在不先猜“该加哪个元件”的情况下，检测模型是否系统性缺项。
    
- **做法（推荐两阶段，工程上最稳）**：
    
    1. 先用第 1–3 步得到“最佳电路参数” θ*.
        
    2. 固定 θ*，对残差随频率的结构做 GP：
        
        - 目标可以选 `y(f)=Re(Zd - Zm(θ\*))` 和 `y(f)=Im(...)`（分别训练两个 GP），输入用 `x=log10(f)`。
            
        - 用 `sklearn.gaussian_process.GaussianProcessRegressor`，核函数用 `RBF + WhiteKernel`（或 `Matern + WhiteKernel`）。
            
        - 看 GP 的预测幅度/相关长度：若 GP 学到明显、平滑且幅度不小的结构残差 → **模型结构不足**；若 GP 只学到接近白噪声 → **模型基本够**，瓶颈在拟合设定/噪声。
            
- **输出要求**：画/导出“原始残差 vs GP 平滑残差”，并标注在哪些频段结构性偏差最大（这直接提示你该加什么机制/支路）。
    

### 5) AIC/BIC/验证集的模型选择（比较不同等效电路）

- **目的**：当你准备尝试“更复杂电路”时，用统计准则避免只是在训练集上过拟合。
    
- **做法**：
    
    - 准备若干候选模型 M₁…M_k（参数个数分别为 p）。每个模型都用相同流程（第 1–3 步的全局+精修、Re/Im、鲁棒设置一致）。
        
    - 计算：
        
        - RSS（或加权 RSS）= 残差平方和；n = 残差点数（注意 Re+Im 拼接后 n=2*频点数）。
            
        - **AIC** = `n*ln(RSS/n) + 2p`；**BIC** = `n*ln(RSS/n) + p*ln(n)`（用同一 RSS 定义保持可比）。
            
    - **验证集**：把频点按频率分块（block）划分 train/val（避免相邻频点高度相关导致“泄漏”），用 train 拟合、val 评估。
        
- **判别**：复杂模型若在 **BIC/验证集** 上稳定胜出 → 结构确实需要更复杂；若只在训练 RSS 赢但 BIC/验证不赢 → 多半过拟合/不可辨识。

结果：

1. 找到了两个不同吸引盆地（basin）
- 全局 + 多起点是有意义的

3. 三个频段各代表什么“可能缺口”
图里蓝色残差在这些位置附近都有成片的波形（不是针尖），结合 peaks 大致可以这样理解：
 **~1e4 Hz（1.19e4）**：一个较宽的“慢变化”偏差
- 常见原因：某个中低频极点/零点没对上（比如某个 RC 支路的时间常数不对，或需要一个额外的耗散元件/CPE）
**~3–4e4 Hz（3.5e4–3.9e4）**：Re/Im 同时明显
- 很像一个额外的动态环节开始起作用（额外的寄生 L/C 或额外支路带来的相位/幅值变化）
 **~2e5 Hz（1.96e5–2.34e5）及 ~3e5（3.08e5）**：更高频的结构偏差
- 常见原因：高频寄生（ESL/ESR 分布、走线电感/并联电容、皮肤效应导致的频率相关电阻等）在现有模型里没表达
 总之：这些峰更像“少了一个（或一对）额外极点/共振相关机制”，而不是“权重/损失函数没调好”。

3. ~1e5 附近超大残差
图中10^5附近 Re/Im 都有非常夸张的正负摆动，且红线在那段出现“几乎水平 + 大不确定度带”的样子，通常意味着在那一段做了某种处理，例如：把那段当作 outlier 降权/屏蔽了（GP 不敢学，或被迫不学）， 或者 GP 被设成必须平滑，无法跟随那么剧烈的变化，于是干脆“放弃解释”，用不确定度覆盖。基本可以断言现有等效电路**缺了一个强共振支路或耦合机制**，必须改模型。可以理解为“少了一个弱的动态环节”，**用一个小的 RC（或 CPE, Constant Phase Element（常相位元件））支路**往往能补上这类“起伏但不形成尖峰”的细节；也可能是“寄生 L/C + 较大阻尼”导致的低 Q 二阶效应，但用 RC/CPE 往往是最小代价的第一步。
