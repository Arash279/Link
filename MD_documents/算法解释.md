# 算法核心：

全局 + 局部两阶段优化：先由解析模型构造完整阻抗网络 Ztotal，随后做log-bounds scaling:
![[Pasted image 20260311214648.png]] 
然后优化时用 global-to-local结构，先用 DE （Differential Evolution）做一次较轻量的全局粗搜索，再从全局候选点和随机采样点中挑选较优初值，交给 SciPy least_squares（最小二乘）做局部精修。拟合目标是复阻抗 Re/Im 残差；同时使用了soft_l1 robust loss减少局部异常点和尖峰的影响。

# 选择DE的原因：

1. 通过前面的解析推导，已经能够给出一组接近真实值的初始参数，因此优化的目标并不是在整个高维空间中进行完全盲目的搜索，而是对一个相对较小的参数邻域进行精细调整。这种情况下，DE作为轻量级全局优化算法，可以以较少的函数评估次数在参数空间中进行一次粗略探索；随后利用最小二乘算法进行局部优化，则可以充分利用梯度信息快速收敛到最优解。由于最小二乘方法在处理连续参数的非线性拟合问题时具有较高的收敛效率，其所需的模型评估次数通常远少于纯进化算法，因此整体计算开销较低。
   
2. 相比之下，遗传算法（GA）属于完全基于群体进化的全局搜索方法，其优势主要体现在缺乏先验信息或存在复杂离散结构的优化问题中。但这里参数均为连续变量，并且已经通过解析模型获得了合理的初始估计，GA 并不能有效利用这些先验信息，需要大量模型评估才能逐步逼近最优解。由于每一次评估都需要重新计算完整的频率响应模型，GA 的总体计算成本会明显高于“DE 粗搜索 + 最小二乘精修”的组合策略。

3. 加入 frequency weights，可自动强调斜率大、结构信息强的频段。具体而言，权重的计算方法：
	3.1 先把频率变到对数坐标：
		logf = np.log10(f_hz)
	3.2 看 sum ( 幅值曲线对 log10(f) 的斜率, 相位曲线对 log10(f)的斜率 )；共振、反共振、相位快速上升/下降的地方，都会有更大的 score。反过来，如果某段曲线很平，幅值和相位都几乎不动，那么 score就会比较小：
		logmag = np.log10(np.abs(Z_data))
		phase_rad = np.unwrap(np.angle(Z_data))
		dlogmag = np.gradient(logmag, logf)
		dphase = np.gradient(phase_rad, logf)
		score = np.abs(dlogmag) + np.abs(dphase)
    3.3 归一化（除中位数）；上下限裁剪：
	    score_med = np.median(score) + 1e-12
		w = score / score_med
		w = np.clip(w, min_w, max_w)
   
4. 拟合完成后做 GP residual analysis，用高斯过程分析残差在哪些频段仍有系统性结构，从而反推模型缺失的是哪类寄生支路。

# 评估指标：

1. **Gaussian Process (GP) residual analysis**，将拟合残差作为函数数据输入高斯过程回归模型，对其在频率域上的相关结构进行建模；如果残差中存在明显的相关结构或局部峰值，则说明模型在相应频段仍存在系统性偏差，这通常意味着等效电路中缺失了某些寄生支路。通过这种方式，可以从残差结构反推出模型改进方向（例如1e7-1e8频段表现尚可，第一个谐振峰附近误差大，说明电机主体模型尚有问题）。
2. **Sum of Squared Errors (SSE)**，所有频点残差平方和，用于衡量模型对实验数据的整体拟合程度
3. **Root Mean Squared Error (RMSE)**，残差均方根，具有与原始阻抗相同的量纲，因此更容易直观理解拟合误差的平均规模。
4. **Akaike Information Criterion (AIC)、Bayesian Information Criterion (BIC)** 两个信息准则，在误差项之外额外引入了对模型参数数量的惩罚项

此外，没有做缩放的原因：实验数据中的阻抗幅值在不同频段变化非常大，跨越多个数量级；如果采用按真实阻抗值进行归一化的相对误差，则会导致低阻抗区域的误差被过度放大（由于分母，即真实值偏小），而高阻抗区域的误差被过度压缩（分母过大，稀释误差的比重）。
此外，如上所属，拟合过程中所用的残差是做了归一化的（为帮助收敛）；仅最后的评价指标没有加归一化，这个随时可以调整（不影响拟合过程本身）。
