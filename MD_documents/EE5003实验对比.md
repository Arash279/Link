更直观一点：

- mag_phase 的 SSE_raw 是 experimental_reim 的 11.39 倍
- mag_phase 的 RMSE_raw 是 experimental_reim 的 3.38 倍

这里有个很重要的判断：best_cost 不能横向比较。因为两边目标函数不是同一个空间，一个是 Re/Im，一个是 log|Z| + phase，所以 137.64 比 1540.10 小，并不代表 mag_phase 更好。真正可比的是你统一关心的原始复阻抗指标，也就是 SSE_raw / RMSE_raw / AIC / BIC，而这些上面 experimental_reim 明显更强。

**怎么理解这个结果**

这说明在你这套模型和数据上，直接在复阻抗 Re/Im 空间拟合，更能把电路参数拉到一个对“原始复阻抗误差”更友好的区域。mag_phase 虽然优化更快、迭代更少，但它更像是在优先照顾对数幅值和相位曲线本身，因此落到复平面误差上会差很多。

从参数上也能看出两边走到了不同区域。mag_phase 相比 experimental_reim，像 Lls、Llr、Lm、Rsw、Csf0、Lad 都有明显偏移，这不是小数值抖动，而是另一组局部最优。
